# Koora Live — ملفات الموقع

## ما الذي يتضمنه المشروع؟
- موقع ثنائي اللغة: العربية والفرنسية.
- تصميم متجاوب للهاتف والحاسوب.
- تبويبات المباريات: الكل، مباشر، قادمة، انتهت.
- وضع تجريبي واضح عند عدم ربط مزود البيانات.
- مساحة مخصصة لإضافة روابط/تضمينات البث الرسمية المصرح بها.
- صفحات من نحن، الخصوصية، الشروط، الاتصال، ومقالتان أصليتان بالعربية والفرنسية.
- Cloudflare Worker لحماية مفتاح مزود النتائج بعيداً عن ملفات الموقع العامة.

## 1) النشر على GitHub Pages من الهاتف
1. أنشئ مستودع GitHub جديداً باسم `koora-live` واجعله Public.
2. ارفع جميع محتويات هذا المجلد إلى جذر المستودع، وليس ملف ZIP نفسه.
3. افتح Settings ثم Pages.
4. في Build and deployment اختر Deploy from a branch.
5. اختر `main` ثم `/ (root)` واحفظ.
6. انتظر اكتمال النشر. سيكون العنوان غالباً `https://USERNAME.github.io/koora-live/`.
7. افتح الموقع وتأكد من ظهور الصفحة الرئيسية والروابط.

## 2) تفعيل النتائج الحقيقية
يستخدم المشروع API-Football من API-Sports. راجع خطط المزود وشروط الاستخدام والتغطية والتراخيص بنفسك قبل الاشتراك:
https://www.api-football.com/documentation-v3

1. أنشئ حساباً لدى المزود واحصل على مفتاح API.
2. ثبّت/افتح Cloudflare Workers وأنشئ Worker جديداً.
3. انسخ محتوى `worker/index.js` إلى ملف Worker.
4. أضف Secret باسم `API_FOOTBALL_KEY` وضع فيه المفتاح. لا تضع المفتاح في `config.js` أو GitHub.
5. أضف Variable باسم `ALLOWED_ORIGIN` واجعله أصل موقعك فقط. مثال: `https://USERNAME.github.io` (لا تضف مسار المستودع).
6. انشر Worker وخذ عنوانه، مثل `https://koora-live-api.ACCOUNT.workers.dev`.
7. افتح `config.js` وضع العنوان في `apiBaseUrl`، دون إضافة `/api`.
8. ارفع `config.js` المحدث إلى GitHub وانتظر إعادة النشر.
9. اختبر `WORKER_URL/api/matches?date=2026-11-17` و `WORKER_URL/api/live`.

ملاحظة: الكود يحدّث الواجهة كل دقيقة، بينما تظل حدود الاستدعاء والتحديث والتغطية خاضعة لخطة مزود البيانات. لا تعرض البيانات كأنها لحظية إذا كان مزودك يؤخرها.

## 3) إضافة بث رسمي
- لا تضف إلا صفحة بث أو مشغل تضمين يملكه الناقل أو لديك إذن كتابي باستخدامه.
- لا تستخدم روابط IPTV أو قوائم M3U أو بث القنوات المدفوعة دون ترخيص.
- لإضافة رابط رسمي، عدّل `officialStreams` في `config.js`:
  `[{ title: "اسم الناقل", url: "https://official.example/match" }]`
- النسخة الحالية تعرض روابط المصادر الرسمية فقط؛ لا يوجد مشغل فيديو افتراضي.

## 4) قبل طلب Google AdSense
- استبدل نص البريد في صفحة الاتصال بعنوان حقيقي.
- راجع سياسة الخصوصية لتطابق أدواتك الفعلية (إعلانات، تحليلات، ملفات تعريف الارتباط).
- أضف محتوى رياضياً أصلياً ومفيداً باستمرار؛ لا تعتمد على جدول نتائج آلي فقط.
- أضف معلومات الناشر وحقوق الصور والشعارات وتأكد من امتلاكك حقوق استخدامها.
- اختبر كل الصفحات والروابط على الهاتف والحاسوب.
- لا تضع إعلانات قرب أزرار التنقل أو عناصر قد تسبب نقرات غير مقصودة.
- القبول غير مضمون؛ القرار النهائي يعود إلى Google ومراجعة السياسات.

المراجع:
- إرشادات جاهزية الموقع: https://support.google.com/adsense/answer/7299563
- أهلية AdSense: https://support.google.com/adsense/answer/9724
- توثيق API-Football: https://www.api-football.com/documentation-v3

## تنبيه
النتائج التجريبية في الصفحة الرئيسية أمثلة فقط وليست مباريات حقيقية. لا تضع مفتاح API في كود الواجهة أو في مستودع عام. ملفات السياسات الحالية قوالب أولية ويجب تخصيصها حسب طريقة تشغيل الموقع والبلد المستهدف.
